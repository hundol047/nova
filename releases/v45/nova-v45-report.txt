수정 사항
- 일반 약 이름의 응답을 인식하고, 알레르기 원인 약과 반응을 별도로 문진.
- 약물 증량/의존 단서가 있으면 취침 전 실제 정수와 밤중 추가 복용을 구분.
- 한 번에 하나의 질문만 전달하고, 중요한 답/진찰 뒤에 제한된 횟수로 재평가.
- 일반 문진에서 규칙 엔진 30턴을 기다리지 않고 12턴 이내에 Doctor 계획 단계로 전환.
- 수면제 사용의 지남력, 성장의 신체 비율, 두근거림의 심장 청진을 선택적으로 추가.
- 거절되거나 미확인인 만성 경과 진찰을 반복 요청하지 않음.
- 말로 표현한 한국어 신장/체중/복용량을 원문 보존 + 단위 표기로 처리.
- 실제 Q/A와 진찰을 S/O에 유지하고, 증상/복약 경과를 HPI에도 연결.
- 환자에게 말하는 계획과 제출하는 P의 검사·추적을 한 계획으로 통일.
- 기존 감별에 필요한 검사 목적/한계 및 결과에 따른 다음 평가를 명시.
- 성장 평가의 단기 결과 확인과 3~6개월 성장속도 추적을 구분.
- 질환 기전, 구체적 경고 증상, 치료 방향, 이해 확인과 추가 질문을 실제 SAY로 전달.
- 주/일 단위의 동등한 재진 답변을 인식하고, 원문과 확인된 정보의 구분을 유지.

검증
834개 회귀 테스트 통과. 신규 경계 검증 29개 포함.
실제 로컬 HTTP + 공식 SDK + 압축본 run.py의 prepare→ready→진료→diagnose 통과.
SAY/EXAM 30자 이하, TEST 미사용, 15칸 기록, 모델 호출, 제출을 확인.
새 ZIP: 115파일, 약 0.93 MB. SDK/진입점/의존성/핵심 안전 파일은 원본과 동일.
합성 환자 3건 평균 턴 29 → 약 32.67; 평균 모델 요청 2.33 → 2.33.
공식 점수·실제 모델 비용·진단 임상 성능은 새로 측정하지 않음.

재빌드

생성 파일: submission/submission.zip

위 검증은 로컬 가짜 서버만 쓰고 대회 개발 키나 비용을 사용하지 않음.
