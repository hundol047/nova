# 교수님 검토 자료 안내

이 묶음은 N.O.V.A. 개발용 규칙의 오류를 찾아 수정하기 위한 자료입니다.
실제 환자 기록이나 교수님의 이름 사용 허가를 요청하는 자료는 아닙니다.
현재 임상의 검토·승인 이력은 없으며, 검토자 항목은 공란입니다.

처음에는 위험 질환 3~5개만 검토해 주셔도 도움이 됩니다. 질환별로
“잘못된 소견 연결”, “음성 검사만으로 배제하면 안 되는 상황”, “최소 검사와
빠진 위험 신호”를 우선 확인하고, 수정안의 근거 문서·버전·절을 남겨 주세요.
검토 가능한 시간과 전문 분야에 맞춰 범위를 줄일 수 있습니다.

- `PROFESSOR_REVIEW_KO.md`: 현재 핵심 질환 34개의 검토 카드. 위험 질환 우선.
- `CLINICAL_REVIEW_FORM.json`: 전체 원본 프로필과 파일 해시, 출처 후보, 검토 입력란.
- `TEST_NOTE_REPLACEMENT_CANDIDATES.json`: 검사 설명 5개의 원문 추출 후보.
  검사 목적 설명이 기존 진단 조건·안전 주의사항을 대체할 수 있는지는 미확인입니다.
- `../../artifacts/clinical_review_pass/field_provenance_inventory.json`:
  기존 데이터의 필드별 목록과 출처 문자열 일치 기록. 일치는 의학적 검증이 아닙니다.

검토 시 각 수정안에 다음을 남겨 주세요.

1. 질환 ID, 파일, 수정할 필드와 현재 문구.
2. 권고 문구와 근거 URL·문서명·버전·해당 절 또는 쪽.
3. 적용 대상, 검사법·단위·시간 조건, 예외와 배제 불가능한 상황.
4. 판단: 적절 / 수정 필요 / 적용 제한 / 근거 부족.
5. 검토자 전문 분야, 검토일, 검토한 범위. 검토하지 않은 항목은 미검토로 유지.

임상 검토와 이용 권한 확인은 별도입니다. 새 자료를 제공할 경우 원저작자,
제3자 자료 포함 여부, 연구 발표·배포·수정 허용 범위를 함께 확인해야 합니다.
교수님께서 내용을 검토하셨다는 이유만으로 제3자 자료의 배포 권한이 생기지는 않습니다.

반영 절차는 근거·권한 확인 → 수정 diff 검토 → 기존 개발 사례 및 안전·효율 회귀
평가 → 명시적 승격 기록입니다. 현재 패킷은 추론 ZIP에 포함하지 않습니다.
합성 사례/mock 평가 수치는 임상 성능이나 실제 고정 모델 성능을 보증하지 않습니다.
