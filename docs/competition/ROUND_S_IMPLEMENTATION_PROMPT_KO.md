## 구현 순서와 완료 기준

1. **부정 범위와 관계 보존** — `matching.py`, `clinical_concepts.py`, `state.py`. 부정 cue의 comma-list 범위를 보존하고 새로운 긍정 절만 분리한다. 자세성 어지러움은 증상과 자세 변화의 연결을 요구한다. 직접/alias/개념 정규화 경로를 함께 검사한다. 가족·과거·문서 진단 기존 회귀를 유지한다.
2. **정보 없음은 근거가 아님** — ASK unknown/응답 거절을 실제 기능 장애와 구분한다. 알려진 절은 유지하고 없는 약명/알레르기/가족 질환을 만들지 않는다. raw 원문은 보존한다. EXAM unknown/rejected/unavailable와 실제 관찰을 구별하고 mapped EXAM coverage를 완성한다.
3. **최종 선택과 위험 계획** — 선택 진단과 독립적으로 실제 관찰된 미해결 위험을 공통 disposition 함수에서 처리한다. 서맥/빈맥과 실신·전실신이 같이 있을 때 양성 진단이 위험을 지우지 못한다. 위험 후보의 존재만으로 무조건 응급으로 올리지 않는다. ECG subtype나 검사 결과를 추정하지 않는다. SOAP/짧은 설명/metadata는 같은 selected_id와 근거 snapshot을 사용하고 working diagnosis와 확실성의 다른 의미를 명시한다.
4. **초기 정보 수집·새 표현** — 특정 정답 순위가 이미 높아야만 질문하는 순환을 줄인다. 실제 측정 이상+증상 군집에 근거해 질문하며 약 하나·쇠약 하나로 전해질 이상을 우선하지 않는다. 양성 두통의 양측 압박성 표현은 제한된 개념으로 매칭한다. 임상 규칙·표현의 출처를 기록한다.
5. **남은 위험 누락 분석** — RoundM096/ValO11에서 초기 실제 관찰과 기본 No의 충돌을 확인한다. 확인된 기전만 수정하고 정답 이름·case ID·특정 질환 쌍으로 순위를 바꾸지 않는다. label 계층과 실제 추론 오류를 분리한다.

개발 회귀에서 추가로 확인한 계약: AND 복합 질문의 단순 No를 각 항목의 부정으로 분해하지 않는다. 객관적으로 측정된 소견과의 충돌을 남긴다. 흔한 동반 증상의 부재와 강한 객관적 반증을 구분하여 증상 점수 상한의 비대칭을 막는다. 갑작스럽다는 시간 표현만으로 다른 증상을 생성하지 않는다. 미분화 SOAP에서 누락 정보를 ‘없음’으로 표시하지 않는다. 이 변경도 전체 위험 회귀를 통과해야 하며 평균 정확도 상승으로 새 위험 누락을 허용하지 않는다.

## 검증 계약

- 기존 R/P/Q/예선/이전 검수 사례는 개발·회귀 자료다. 기존 정답·분모·scorer·simulator 응답을 바꾸지 않는다. Top150/Weighted RRF/Top25 유지, 근거 없는 질환 프로필 확대 금지.
- 새 최소 대조쌍과 전체 adapter 경로에서 허위 support, 위험 과소 판단, generic 근거로 인한 과잉 판단, 알려진 증상 소실을 검사한다. 기존 테스트 삭제/단언 완화 금지.
- 구현 완료 후 별도의 새 합성 사례와 행동 계약을 실행 전에 동결·hash. 같은 fixture를 기준선/최종 코드에 실행. 결과 이후 튜닝 금지. 작성자는 기존 실패를 읽었으므로 독립 임상 검증이라고 하지 않는다.
- 전체 회귀, 동일 조건 예선230/P/Q/R, TEST 경로 회귀/M, 제출 mirror byte sync, ZIP audit/격리 mock을 실행한다. runtime SHA, 테스트의 pass/fail/skip, 각 새 정답/새 오답, 위험 누락/과잉 판단, 턴 증가를 사실대로 기록한다.
- 검사 불가를 음성으로 만들지 않으면서 유한 턴에 종료한다. 예선 TEST 금지. 외부 LLM 연결/모델 다운로드/학습/공식 schema 추측/blind v18·v19 실행 금지.
- 후속 위험 결함이나 성능 미달은 FAIL/부분 완료로 보고한다. 실제 모델과 공식 인터페이스는 실제 증거 없으면 미검증이다. 최종 보고에는 구현/회귀/새 사례/패키지의 판정을 분리한다.

기존 상세 평가 기록 52개 공개는 자동 승인 검토로 보류된 상태다. 이번 수정 권한을 그 자료의 별도 공개 승인으로 확대 해석하지 않는다.
