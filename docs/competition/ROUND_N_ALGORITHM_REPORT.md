## 3. 변경 사항과 목적

각 변경은 스위치로 끌 수 있고(기본값 ON), 단계별로 ablation을 수행했습니다.

1. **임상 개념 정규화**: `nova_agent/clinical_concepts.py`, `NOVA_CONCEPT_NORMALIZATION`.
   - 부정과 과거력을 인식하는 정규식 개념으로 일상 표현을 KB 표준 문구에 대응시킵니다.
   - 대상: 수막자극, 광과민, CSF 세포증가, 월경 지연, 질출혈, 흑색변/혈변/토혈, 실어/구음장애/안면마비, 호흡곤란, 기립 시 어지럼, 실신 전구증상, 빠른 회복, 배뇨통, 빈뇨.
   - 사례 ID나 정답 라벨을 쓰지 않는 일반 언어 패턴입니다.
2. **KB 수정**: 충수염 확진 소견을 "right lower quadrant rebound tenderness"로 국소화했습니다(출처 메모 포함).
3. **근거 해석 v2** (`NOVA_EVIDENCE_V2`):
   - 별칭은 단어들이 한 절 안에 붙어 있을 때만 매칭합니다. 연결동사, 정도부사, 구동사 불변화사는 투명하게 취급하고, 비라틴 문자(한국어)는 기존 동작을 유지합니다.
   - 라우팅은 구동사 관용구("burning up")에만 근접성을 요구합니다.
   - 음성 β-hCG는 자궁외임신에 대한 반대 근거로 씁니다. troponin과 D-dimer에는 적용하지 않습니다.
   - 누운 자세/선 자세 혈압이 수축기 20 이상 또는 이완기 10 mmHg 이상 떨어지면 "orthostatic drop"으로 해석합니다.
   - "after eating"을 알레르겐 별칭에서 제거했습니다.
4. **행동 선택 v2** (`NOVA_ACTION_V2`): 핵심 병력(onset, 동반증상, 과거력)을 확보한 뒤에는, 종료를 막고 있는 위험질환의 미완료 최소 검사에 +0.5 보너스를 줍니다.
5. **진단 추적**: `StopDecision.blockers` 필드를 추가해 종료를 막는 이유를 기록합니다.
