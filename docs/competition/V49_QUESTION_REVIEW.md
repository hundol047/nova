# v49 질문 단위 재검토와 35~49턴 진료

최신 사용자 보고는 정보수집 6.86/25, 진단추론 8.33/15, 검사·추적
5.69/10, 안전 12.50/15, 의사소통 5.67/15, 효율 18.86/20으로 합계
57.91점이다. 직전 보고 60.05점보다 2.14점 낮다. 실제 평가 대화가
제공되지 않아 개별 감점 원인을 단정할 수 없다. 이전에 제공된 시작 정보와
종료 결과 파일만으로 실제 문진 내용이나 v48의 실패를 재구성하지 않았다.

## 질문 검토에서 바꾼 것

- 알레르기 선별 질문과 원인 약·반응, 가족력 선별 질문과 구체적 질환,
  부모 각각의 키, 복약 이름·빈도·용량을 서로 다른 질문으로 처리한다.
  넓은 모델 topic 이름 때문에 필요한 세부 질문이 차단되지 않게 했다.
- 증상의 위치·양상·정도·지속 시간·빈도·악화/완화·이전 발현을 구분한다.
  증상별 관련 질문을 먼저 제안하고, 여러 답을 요구하는 질문을 차단한다.
- 빈 Doctor 계획에 대해 배뇨·호흡·흉통·복통·두통·체중·수면·성장의
  보완 질문과 관련 신체진찰을 선택한다. 원인 미상의 다른 증상에서는
  일반 현병력 질문을 보완하고 모델의 환자별 판단을 요청한다.
- 기존 수면제 노출의 용량·횟수·기간·금단 질문을 보존했다. 노출을
  확인하지 못한 불면에 약물 사용을 가정하지 않는다.
- 모름, 거부, 질문을 나눠 달라는 응답을 정상 소견으로 쓰지 않는다.
  실제 질문·답변·진찰 및 출처 ID를 계속 기록한다.
- 일상 한국어의 '아파요'도 복통·흉통·두통의 관련 질문/진찰 경로로
  분류하도록 확인했다. 단순한 단어 변형 때문에 관련 진찰을 빠뜨리지 않는다.
- 소아의 수술력 질문을 음주 질문으로 오인하던 부분 문자열 필터를
  수정했다. 수술력은 물을 수 있고 일반 음주·흡연 질문 제한은 유지한다.
- 모델 계획이 비어도 초반에는 기본 안전 병력과 주호소 감별 질문을
  우선한다. 사회력부터 채우느라 관련 증상 질문이 뒤로 밀리지 않게 했다.

## 턴 수·추론·설명

안정 환자는 35~49턴을 목표로 한다. 문진·진찰·환자 걱정 확인은 최대
35턴, 설명을 위해 14턴을 남긴다. 모든 SAY/EXAM 전송에 49턴 상한을
적용한다. 즉시 이송, 임박한 마감, 서버 종료나 환자 거부를 무시하고
횟수만 채우지는 않는다. 필요한 질문이 모두 소진된 경우도 억지 반복하지 않는다.

한 번에 최대 4개 행동을 계획하고 관찰 결과를 다시 검토한다. 모델 계획
검토는 최대 12회다. 최종 판단은 지정 Doctor 모델에 6,000토큰/high로
요청하고, 시간이 충분한 안정 환자에서는 관찰과 초안을 이용해 한 번 더
검토한다. 잘못된 관찰 ID를 인용한 수정안은 이전 근거 있는 판단을 지우지 않는다.

검사 목적·시점·이상/정상 결과에 따른 조치와 재진 시점·장소·확인 항목을
유지한다. 환자에게 이유·걱정에 대한 답, 검사 시점, 재진 내용, 주의사항을
실제로 전달한다. 환자의 추가 질문에도 현재 승인된 계획의 이유와 주의사항을
사용한다. 긴 검사 설명은 완결된 짧은 문장으로 나누고 의미를 잘라내지 않는다.

코딩 도구에서 읽거나 사용하지 않았다. blind v18 재실행도 하지 않았다.

새 질문 템플릿은 개발자가 작성한 보완 문진이며 임상 전문가가 검증한
프로토콜로 표시하지 않는다. 위험 임계값이나 약물 처방은 새로 추가하지
않았다. 기존 안전 규칙, 관찰 출처 검사와 제출 마감을 유지한다.

정확한 검사 결과·비교·ZIP 해시는 `artifacts/releases/nova-v49-publication.json`
및 같은 디렉터리의 보고서에 기록한다. 비교 사례 8개는 새로 작성한
가상 환자이고 Doctor는 고정 응답이다. 질문 실행·중복 방지·종료 턴과
전달된 설명을 검사하며 임상 정확도나 정보수집 점수를 채점하지 않는다.
만점과 모든 영역의 상승은 실제 공식 재채점 전에는 확인할 수 없다.
