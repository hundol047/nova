# NOVA 정확도 개선 사이클 3 — 2026-10-03

실제 확인된 개선은 합성 목표 라벨 일치 770/800 → 772/800 (96.25% → 96.50%)이다.
99.99% 또는 임상 정확도 달성 주장은 하지 않는다. 모델 학습이 아닌 코드 수정이다.

| 항목 | 기존 400개: 전 → 후 | 추가 400개: 전 → 후 |
|---|---|---|
| 전체 목표 라벨 일치 | 383 → 384 (96.00%) | 387 → 388 (97.00%) |
| 쉬운 200개 | 200 → 200 | 200 → 200 |
| 어려운 200개 | 183 → 184 (92.00%) | 187 → 188 (94.00%) |
| 위험 사례 정답 일치 | 182/194 → 182/194 | 190/197 → 190/197 |
| 위험 사례 최종 경고 누락 | 15 → 15 | 13 → 13 |
| 비위험 사례 최종 경고 발생 | 65 → 65 | 63 → 61 |

전후 입력 파일 해시와 결과 파일 해시를 검증했다. 두 코호트 각각 정답으로 바뀐 사례 1개,
정답에서 오답으로 바뀐 사례 0개. 수정된 사례들은 같은 기존 원형의 서로 다른 합성 변형이며,
독립된 두 임상 성공 사례가 아니다. `comparison.json`에 해당 ID를 보관한다.

## 원인과 변경

- 위치를 명시한 폐엽 경화가 기존 `focal consolidation` 근거와 연결되지 않아 검사 표현에 따라 순위가 달라졌다. 좌/우 및 상/중/하엽과 lobar 표현을 좁은 범위의 동의 표현으로 연결했다.
- 검사 결과 문자열의 과거·가정·불확실 문장이 현재 객관적 근거로 계산될 수 있었다. 기존 검사실 결과의 현재 문장 필터를 신체검사·영상의 확증 근거에도 재사용했다.
- 점수 가중치·확정 기준·정답 라벨·scoring_expected 플래그는 변경하지 않았다. 벤치마크 ID나 정답을 런타임에 넣지 않았다. 모든 검사 시점 표현을 이해하는 완전한 시간 추론기는 아니다.

의학적 배경 확인: Merck Manual Professional, Community-Acquired Pneumonia, 2026-10-03 확인.
https://www.merckmanuals.com/professional/pulmonary-disorders/pneumonia/community-acquired-pneumonia
위치가 명시된 경화 소견이 기술될 수 있음을 확인했다. 이 자료가 NOVA의 임상 검증을 의미하지는 않는다.

## 테스트와 범위

새 단위 테스트는 수정 전 9 실패/4 통과, 수정 후 13 통과. 부정·과거·가정 소견과 다른 영상 소견을 양성으로 처리하지 않는지 검사했다.
전체 비-API 회귀: **646 통과, 1 건너뜀** (`regression.txt`). API TestClient의 기존 실행 문제는 해결되지 않아 `tests/test_production_api.py`를 명시적으로 제외했다.
제출 패키지 빌드 및 소스 동기화 검사 통과. 배포하지 않았다.

기존 합성 자료 800개를 mock provider의 질문/검사/관찰 루프로 재평가했다. 실제 LLM 호출은 0.
두 코호트는 정확히 같은 입력은 없으나 과거 개발에 노출된 원형 사례가 겹친다. 독립 테스트가 아니다.
정보 부족 또는 심층 프로필 미구현 사례도 전체 분모에서 제외하지 않았다. 쉬운 군 100%를 전체 성능으로 표현하지 않는다.
동일한 임상 정보를 문장만 바꿔 반복 평가해도 독립 표본 수가 증가하지 않는다.
