## 자료와 재현

기존 동결 50,000개 합성 코퍼스에서 seed `compliance-cycle4`로 난이도별 200개를 원형 사례별
순환 선택했다. 이전 두 코호트의 800개 입력 해시는 제외했으며 정확한 입력 중복은 0이다.
원형 사례는 쉬운 군 45개/어려운 군 146개, 목표 진단군 34개/42개다. 과거 개발에 노출된
원형의 변형이므로 독립 검증군도, 400명의 실제 환자도 아니다. 영어 중심에 다국어 사례가
일부 포함된다. 한 번 정한 결과를 보고 사례를 교체하거나 엔진을 재튜닝하지 않았다.

어려운 군에 기존 scoring_expected=False 사례 17개가 포함되어 있다. 전체 목표 일치율은
이를 제외하지 않는다. 기존 채점 가능 플래그만 적용하면 181/183이지만 전체 93%를 대체하지 않는다.

입력 ID·해시와 출력 ID 일치, 결과 파일 SHA-256, 실행 전후 런타임 해시 확인 완료.
