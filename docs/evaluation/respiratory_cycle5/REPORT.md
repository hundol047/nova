# 어려운 사례 개선 결과 — 2026-10-03

기존 세 평가군의 동일 입력 1,200개를 다시 실행해 비교했다. 정답 라벨, scoring_expected,
채점 분모와 점수 가중치는 변경하지 않았다. 고정 LLM 파인튜닝이나 새 모델 학습은 없다.

쉬운 사례는 세 군 모두 200/200을 유지했다. 전체는 1158/1200 → 1163/1200.
개별 사례 비교에서 새 정답 5건, 정답에서 오답으로 변한 사례 0건이다. 새 정답은 모두
동일한 복합 호흡기 원형의 합성 변형이다. 다섯 독립 임상 사례나 새로운 질환 범위의 검증이 아니다.

위험 사례 최종 경고 누락 수는 15/13/15건으로 각 군에서 변하지 않았다.
비위험 라벨 사례 경고 수는 65→64, 61→60, 63→61로 감소했다.
경고 지표는 특정 질환 확인이나 올바른 의료 이용 안내를 입증하지 않는다.

## 실제 수정

- `nova_agent/knowledge/diseases/pulmonary.json`: 청진상 crackles를 독립적인 폐렴 확증 항목에서 제거하고 기존 일반 청진 소견은 유지했다. 천식/COPD 후보의 기침·호흡곤란·호흡곤란 악화 표현을 보완했다.
- `nova_agent/differential.py`: airspace opacity와 기존 infiltrate 항목, 악화되는 호흡곤란의 일반 표현을 좁은 범위로 연결했다. 영상 소견이 감염에만 특이적이라는 뜻은 아니다.
- `submission/`의 대응 파일: 빌드로 동기화.
- `tests/test_respiratory_evidence_balance.py`: 부정 표현, 안정 상태, 영상 근거와 청진 근거 구분 등 7개 검사.

첫 시도는 각 평가군에서 기존 폐렴 정답 1건씩을 잃어 채택하지 않았다. 현재 검사에서
영상의 regional airspace opacity 표현을 인식하지 못한 것이 원인이었고, 이를 보완한
`revised_*` 결과만 최종 수정안의 성능으로 사용한다. 상세 근거는 `RATIONALE.md`에 있다.

## 검증과 제한

전체 비-API 회귀 **663 통과, 1 건너뜀** (`regression.txt`). 알려진 API TestClient 실행
문제로 `tests/test_production_api.py`는 명시적으로 제외되어 아직 미검증이다.
제출 패키지 빌드와 소스 동기화 검사 통과. 입력·결과 해시 및 실행 전후 런타임 해시 검증.

모든 평가는 mock provider를 사용한 기존 합성 개발 사례의 재실행이다. 실제 LLM 호출 0회.
서로 다른 문장이라도 원형이 겹쳐 독립 임상 검증이 아니며, 전문가가 새로 정답을 판정한
자료도 아니다. COPD·심부전 등이 함께 나타나는 원형의 단일 정답은 추가 임상 검토가 필요하다.
이 수치는 확정진단 정확도 또는 99.99% 성능의 근거로 사용할 수 없다.

대회 제출은 실행하지 않았다. 공식 고정 LLM 연결/호출과 공식 인터페이스 확인의 기존
차단 사유는 남아 있다. 다음 우선순위는 전문가 정답 검토, 미구현 심층 프로필, 판단 보류,
남은 위험 경고 누락을 분리해 개선하는 것이다.
