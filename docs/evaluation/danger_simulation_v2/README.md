# 위험질환·고난도 모의 진단 개선 2차

기준 코드 `8eca54a`와 수정 코드를 비교했다. 합성 환자와 mock provider로 실행했으며,
실제 임상 정확도나 실모델 정확도를 검증한 결과는 아니다.

| 평가 | 수정 전 | 수정 후 |
|---|---:|---:|
| 고난도 개발 평가 | 14/24 (58.3%) | 16/24 (66.7%) |
| 그중 위험질환 | 8/15 (53.3%) | 9/15 (60.0%) |
| 새 고정 사례 | 11/12 | 12/12 |
| 새 사례 중 위험질환 | 5/6 | 6/6 |

기존 고난도에서 대동맥박리와 복합 심폐질환 사례가 개선됐고 정답→오답 회귀는 없었다.
고난도 오답 8개는 남아 있으며, Tier-2 질환 7개(소아·임신·신장질환 포함)와 원인 미상의 여행 후 발열 사례다.
복합 심폐질환은 정해진 합성 정답과의 일치이며 실제 동반 심부전을 배제했다는 뜻이 아니다.
평균 대화 횟수는 고난도에서 22.21→23.04회, 새 사례에서 20.92→23.58회로 늘었다.

## 수정 사항

1. 후보 수 제한보다 위험질환과 고정 안전 목록의 보존을 우선했다.
   기존 코드는 안전 목록으로만 검색된 위험질환을 잘라낼 수 있었다.
   후보에 남기는 것과 진단 확정은 별개이며 근거 점수는 여전히 필요하다.
2. 검사 문장에 신체 부위가 있다는 이유만으로 통증으로 해석하지 않도록 했다.
   양팔 혈압 기록이 왼팔 통증으로 잘못 들어가 심근허혈 후보를 올리던 오류를 수정했다.
   영어 통증 동의어와 한국어 통증 표현은 유지한다.
3. 대동맥박리 후보의 통증 표현에 등·흉골·복부 표현을 연결했다.
   이 표현은 증상 근거이며 영상 확진 근거로 사용하지 않는다.
4. `known asthma or COPD`를 두 질환 모두 필요하다는 식으로 처리하던 구성을 정리했다.
   천식·COPD 병력은 위험 맥락으로만 점수를 주고, 병력만으로 현재 악화를 확진하지 않는다.

## 평가 설계

- 기존 고난도 24개: 이미 수정에 활용한 개발/회귀 평가. 정답과 해시를 유지했다.
- 새 12개: 대동맥박리, 기도질환 악화, 급성관상동맥증후군, 정보 부족의 4개 그룹.
  코드 변경 전에 고정했으며 결과를 본 뒤 이 사례에 맞춰 다시 수정하지 않았다.
  단, 같은 개발자가 작성한 합성 사례로서 외부 임상의의 독립 임상 검증은 아니다.
- 기존 표현 변형 72개: 18개 원본 사례군의 회귀 평가.
  최종 코드에서의 결과는 `robustness_final.json`에 기록한다.
- 전체 소프트웨어 테스트와 제출용 독립 실행도 확인한다. 결과는 `tests.txt`에 기록한다.

채점기, 기존 사례의 정답, 시뮬레이터의 검사 결과 전달 규칙은 변경하지 않았다.
이전에 확인된 검사 키 불일치와 희귀질환의 검증되지 않은 추론 규칙은 여전히 한계다.
더 많은 후보를 보존하므로 필요한 문진·검사가 늘 수 있다. 정답률뿐 아니라
평균 대화 횟수와 검사 수도 결과 JSON에 함께 남겼다.

## 근거

- [2022 ACC/AHA 대동맥질환 가이드라인](https://www.jacc.org/doi/10.1016/j.jacc.2022.08.004): 급성 대동맥 증후군의 흉부·등·복부 통증 양상 참고.
- [NHLBI COPD 증상](https://www.nhlbi.nih.gov/health/copd/symptoms): 증상의 악화 및 동반 질환 맥락 참고.

새 규칙은 내부 작성 휴리스틱이며 전문가 검토를 완료한 임상 규칙으로 승격하지 않았다.

## 재현

```sh
python scripts/run_danger_simulations.py --suite reference --output /tmp/reference.json
python scripts/run_danger_simulations.py --suite validation --output /tmp/validation.json
python scripts/run_danger_simulations.py --repo /tmp/nova-danger-baseline --suite validation --output /tmp/baseline.json
python -m pytest tests/ -q --tb=short
```

기준 고난도 결과 `reference_before.json`은 동일 기준 커밋의 직전 실행 기록을 보존했다.
모델 가중치 학습이나 백그라운드 반복 실행, 배포, 원격 push는 수행하지 않았다.

최종 회귀: **72/72**, 전체 테스트: **526 passed, 1 skipped, 0 failures, 0 errors**.
텍스트 출력이 일부 누락되어 완결된 JUnit XML(`tests.xml`, 527개 testcase)로 결과를 확인했다.
제출용 코드 동기화와 독립 실행 smoke test도 통과했다.
