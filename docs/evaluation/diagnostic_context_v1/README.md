# 고난도 평가 3차 — 근거 없는 확진 제한

기준 커밋 `5548d5b`. 모든 결과는 mock provider와 합성 사례에서 나온 개발·회귀 결과다.
실제 임상 정확도 또는 확률 보정 결과가 아니다.

| 지표 | 수정 전 | 수정 후 |
|---|---:|---:|
| 전체 고난도 정답 | 16/24 (66.7%) | 17/24 (70.8%) |
| 질환명이 있는 고난도 정답 | 15/22 (68.2%) | 15/22 (68.2%) |
| 위험질환 정답 | 9/15 (60.0%) | 9/15 (60.0%) |
| 근거 부족 사례의 판단 유보 | 1/2 | 2/2 |
| 새 고정 검증 사례 | 4/8 | 8/8 |

이번 개선은 여행 후 발열 사례를 신우신염으로 잘못 확정하던 것을 판단 유보로
바꾼 결과다. **위험질환 및 이름 있는 질환의 정확도는 이번에 오르지 않았다.**
임의로 정답을 바꾸거나 해당 사례를 분모에서 제외하지 않았다.

## 수정과 검증

신우신염을 최종 출력할 때 현재 요로 관련 증상·진찰 또는 소변검사 등 국소화
근거가 있는지 확인한다. 발열·오한·구역만으로는 이 진단을 확정하지 않는다.
배뇨 증상이 없어도 실제 소변검사 근거가 있으면 이 제한을 통과할 수 있다.
이것은 내부 작성 판단 유보 규칙이지, 신우신염을 배제하거나 확진하는 임상 기준이 아니다.
후보와 위험도 판단, 추가 검사 선택은 유지한다.

모델이 출력한 supporting_evidence 문구만 믿지 않고 실제 환자 상태에서 근거를
찾는다. 과거·가족력, 부정·추정 소견은 이 확인을 대신하지 않는다.

새 검증 데이터는 코드 수정 전에 고정한 4개 증상군의 8개 대화다.
요로 근거가 없는 발열 4개와 요로 근거가 있는 사례 4개를 짝지었다.
검증 결과를 본 뒤 이 사례에 맞춰 규칙을 재수정하지 않았다.
같은 개발자가 작성한 소규모 합성 데이터로 외부 임상의의 독립 평가가 아니다.
기존 고난도 24개는 수정에 사용한 개발 데이터이며 계속 그 상태로 보고한다.

## 아직 해결되지 않은 한계

남은 정답 대상 7개는 Guillain–Barré syndrome, 심낭염, 갈색세포종, Fabry병,
크루프, 전자간증, 급성 신손상이다. 등록된 Tier-2 명칭이지만 현재 기본 결정론적
감별 지식베이스에는 이 진단들의 실행 규칙이 없다(`remaining_coverage.json`).
따라서 동일 사례를 반복 실행하거나 점수만 조정해 이 부분이 학습되는 구조가 아니다.
질환별 근거·감별·검사 규칙과 독립 검증이 필요하며, 기존 임상 검증 게이트나
NOT_VERIFIED 상태를 임의로 해제하지 않았다. 모델 가중치 재학습도 수행하지 않았다.

## 근거

[NIDDK 신우신염 진단](https://www.niddk.nih.gov/health-information/urologic-diseases/kidney-infection-pyelonephritis/diagnosis)은 병력·진찰·소변검사·배양 및 필요한 영상의 역할을 설명한다.
이 자료를 참고해 국소화 없이 최종 진단을 확정하지 않는 내부 안전 규칙을 작성했다.
NIDDK가 이 코드나 정량적 판단 유보 기준을 검증한 것은 아니다.

## 재현

```sh
python scripts/run_danger_simulations.py --suite reference --output /tmp/reference.json
python scripts/run_danger_simulations.py --suite validation --fixture-folder evaluation/diagnostic_context_v1 --output /tmp/context.json
python -m pytest tests/ -q --tb=short
```

비교 결과와 전체 사례 경로를 JSON에 보존한다. 배포·원격 push는 수행하지 않았다.

최종 검증: 기존 회귀 **72/72**, 전체 테스트 **540 passed, 1 skipped**.
의존성 deprecation 경고 1개가 있으며, 제출용 코드 동기화·독립 실행 검사도 통과했다.
