# 수정 후 모의평가 결과

| 지표 | 기존 400개: 수정 전 → 후 | 추가 400개: 수정 전 → 후 |
|---|---|---|
| 목표 정답 일치 | 383/400 → 383/400 (95.75%) | 387/400 → 387/400 (96.75%) |
| 위험 사례 정답 일치 | 182/194 → 182/194 | 190/197 → 190/197 |
| 위험 사례 최종 경고 발생 | 172/194 → 179/194 (92.27%) | 178/197 → 184/197 (93.40%) |
| 위험 사례 최종 경고 누락 | 22 → 15 | 19 → 13 |
| 비위험 사례 최종 경고 발생 | 65/206 → 65/206 | 63/203 → 63/203 |

정답률 상승은 확인되지 않았다. 확인된 개선은 두 평가군에서 위험 경고 누락이 총 41건에서 28건으로 감소한 점이다. 비위험 라벨 사례의 경고 수는 늘지 않았다. 이 경고 지표는 질환별 확정진단이나 적절한 의료 이용 안내를 검증하지 않는다.

두 평가군의 입력 800개는 정확히 중복되지 않지만 원형 사례는 겹친다. 추가군도 이번 수정 검토에 사용했으므로 독립 검증으로 표시하지 않는다. 기존 정보 부족 사례도 분모에서 제외하지 않았으며 상세 scoring_expected 집계는 각 difficulty_safety.json에 남겼다.

다국어 증상을 인식한 뒤에도 경고 관련성이 없다고 처리되던 오류를 특정 출혈·신경학적 징후에 한해 수정했다. 과잉 경고가 늘어난 두 중간 시도는 채택하지 않았다. 단순 시뮬레이션 반복이나 합성 라벨 학습으로 정확도를 올렸다는 주장은 하지 않는다.

남은 경고 누락 28건과 기타 오답은 개별 원인 검토가 필요하다. 실제 환자 임상 정확도, ICD-11 전체 질환 지원률, 독립 외부 검증 결과는 없다. API 테스트는 기존 실행 문제로 제외되어 별도 해결이 필요하다.
