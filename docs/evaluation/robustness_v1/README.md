# 모의 진단 확대 및 문장 해석 개선 — 2026-10-02

기준 코드: `10b7f22`. 결정적 mock 제공자를 사용했습니다. 모델 가중치 재학습이나 실제 환자 검증을 수행하지 않았습니다.

## 실험 설계

기존 개발 8개 증례와 일반화 18개 증례에 원본, 대문자, 여분 공백, 세미콜론을 문장 마침표로 바꾸는 네 가지 형태를 적용했습니다. **26개 원본 증례, 104개 시나리오**입니다. 104명의 독립 환자나 104개 질환을 뜻하지 않습니다.

- 개발용: 8개 가족 × 4형태 = 32개.
- 최종 확인용: 별도 18개 가족 × 4형태 = 72개. 원본은 과거에 사용한 평가 자료이므로 새로운 독립 임상 검증은 아닙니다.
- 입력 및 정답은 실행 전 동결했고 SHA-256을 `evaluation/robustness_v1/manifest.json`에 보존했습니다.
- 기준 코드와 최종 코드가 동일 입력으로 ASK/EXAM/TEST를 직접 선택하고 최종 진단까지 진행했습니다. 원본/변형 모두 포함하며 실패를 제외하지 않습니다.
- 마지막 수정은 개발용 증례와 별도의 문장 해석 검사에 근거했습니다. 최종 코드를 고정한 뒤 확인용 결과를 읽었으며, 해당 실패 결과에 맞춘 추가 수정은 하지 않았습니다.

## 수정한 오류

1. `focal consolidation is absent`와 같이 부정 표현이 소견 뒤에 오면 양성으로 읽었습니다. 부정된 절을 근거에서 제외하도록 수정했습니다.
2. 부정 소견 뒤의 별도 긍정 문장까지 지워지는 경우를 수정했습니다.
3. 환자 답변의 긍정 증상 뒤에 마침표로 부정 문장이 이어질 때, 답변 전체가 부정으로 분류되는 문제를 수정했습니다. 소수점을 보존하면서 문장 경계와 줄바꿈을 나눕니다.

첫 두 문제의 독립적인 문장 해석 검사 20개에서 기준 코드는 17개 실패, 수정 코드는 모두 통과했습니다. 환자 답변 경계 검사 4개를 추가했습니다. 이 수치는 진단 정확도가 아닌 텍스트 해석 검사 결과입니다.

## 범위와 한계

특정 문장 표현을 더 안정적으로 처리하도록 규칙을 수정했습니다. 모든 임상 상황을 이해하는 의미 분석 모델로 바뀐 것은 아닙니다. 새 질환 22,047개는 여전히 미검증 후보이며 자동 진단에 활성화하지 않았습니다. 모의 사례 수를 늘린 것이 해당 질환 전체를 평가했다는 뜻은 아닙니다. 기존 확장 게이트를 유지합니다.
