# 모의평가 및 판단 보류 개선 — 2026-10-03

수정 전후 동일 입력 1,200개를 실행했다. 정답률 상승은 확인되지 않았다.
대신 잘못된 세균성 수막염 명칭을 내보내던 12건이 unknown으로 바뀌었다.
이 사례들은 채점상 여전히 목표 라벨 불일치로 남기며, 정답 처리하거나 분모에서 빼지 않는다.

| 평가군 | 어려운 200개 정답 | 전체 400개 정답 | 잘못된 명칭 → unknown |
|---|---|---|---|
| 최초 | 185/200 (92.5%), 유지 | 385/400 (96.25%), 유지 | 5 |
| 추가 | 190/200 (95%), 유지 | 390/400 (97.5%), 유지 | 3 |
| 최근 | 188/200 (94%), 유지 | 388/400 (97%), 유지 | 4 |

기존 정답이 오답으로 바뀐 사례 0건. 최종 안전 경고 유무가 바뀐 사례 0건.
위험 경고 누락은 각 군 15/13/15건으로 남아 있어 해결 완료가 아니다. 특히 위험 질환을
올바르게 식별한 대신 unknown으로 바꾼 것은 아니지만, 보류 자체가 적절한 진료 안내나
안전성을 임상적으로 입증하는 것도 아니다.

변경된 12건은 정보 부족 두통, 약물 관련 발진·점막 증상, 임신 관련 두통/고혈압의
세 기존 원형에 속한 반복 변형이다. 독립된 12명의 환자 검증이 아니다. 후자의 위험
사례는 해당 질환군에 대한 독립 근거 검토와 안전 안내가 추가로 필요하다.

## 변경 파일과 이유

- `nova_agent/knowledge/diseases/neuro.json`: 수막염 최종 명칭 확정에 구체적인 현재 문맥을 요구한다. 후보 탐색과 위험 경고에서는 제거하지 않는다.
- `nova_agent/differential.py`: 현재 문맥 검사에 기존 제한된 동의 표현을 재사용한다. 다국어 표현이 다르다는 이유만으로 문맥이 없다고 처리하지 않도록 한다.
- 대응 `submission/` 파일: 빌드로 동기화.
- `tests/test_meningitis_abstention.py`: 정보 부족, 부정 표현, 가족력, 현재 구체적 소견, 위험 경고 유지 검사.

근거와 제한은 `RATIONALE.md` 참조. 규칙은 임상적 배제 기준이 아니며, 소견이 없다고
수막염을 배제하거나 평가를 지연해서는 안 된다. 모델 가중치, 정답 라벨, 채점 기준은 그대로다.

## 검증 및 다음 작업

전체 비-API 검사 **672 통과, 1 건너뜀**. API TestClient의 기존 문제로 해당 파일은
명시적으로 제외되어 미검증이다. 제출 빌드와 소스 동기화 통과. 전후 입력 해시, 결과
파일 해시, 실행 전후 런타임 해시 확인. 사례별 비교는 `comparison.json`에 보관했다.

이번 작업은 규칙 엔진 수정과 모의평가이며 딥러닝 재학습이 아니다. mock provider,
실제 LLM 호출 0회. 기존 개발 합성 자료의 재실행이므로 임상 정확도/독립 테스트로 주장하지 않는다.
공식 LLM 연결과 대회 인터페이스 검증은 여전히 미완료이며 대회 제출·배포는 하지 않았다.

후보를 구분할 수 있는 추가 질문, 독립 평가 자료 확보다. 보류를 강제 진단으로 바꿔
목표 백분율을 맞추지 않는다.
