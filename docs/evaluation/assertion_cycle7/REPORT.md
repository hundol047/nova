# 문장 경계 처리 개선 사이클

## 변경과 이유

`nova_agent/matching.py`는 긴 보고서 전체에서 단어 겹침을 계산했다. 서로 다른 문장의
신체 위치·통증이나 검사명·이상 소견을 결합해 실제로 없는 진단 근거를 생성할 수 있었다.
이번 수정은 원문 문장·세미콜론·줄바꿈 경계 안에서만 매칭한다. 쉼표 연결과 소수점은 유지한다.
질환별 정답, 특정 증례 ID, 새 진단명은 런타임에 추가하지 않았다.

변경 파일: matching.py 및 빌드된 submission 사본, tests/test_matching_assertion_boundaries.py,
scripts/run_external_nine.py의 출력 경로 옵션, CHANGELOG 및 이 평가 기록.

## 검증

| 구분 | 수정 전 | 최종 수정 후 |
|---|---:|---:|
| 새 문장 경계 오류 검사 7개 | 0/7 | 7/7 |
| 동일한 합성 400개 | 385/400 (96.25%) | 385/400 (96.25%) |
| 외부 표적 복합 증례 9개, 완전 정답 일치 | 0/9 | 0/9 |

새 문장 경계 검사는 개발자 작성 소프트웨어 테스트다. 임상 정확도 또는 독립 검증이 아니다.
13개 신규 단위 테스트에는 위 7개 오류와 정상 양성·부정·소수점·쉼표 보존 검사가 포함된다.
기존 테스트와 합쳐 685 passed, 1 skipped (65.71초).
이전부터 TestClient 정지 문제가 있던 tests/test_production_api.py는 제외했다.
따라서 전체 API 회귀까지 통과했다고 표현하지 않는다.

합성 400개는 입력 파일 바이트까지 동일함을 확인했다. 최종 병명 400개와 최종 위험 플래그
400개가 전후 모두 동일하다. 정답률 상승은 없지만 이번 변경으로 확인된 회귀도 없다.
외부 자료는 기존에 골라 검토한 연구용 9개이며, 임상적 위험도 정답은 없다.
정답·선택지는 엔진 입력에서 제외했다. 실제 LLM 호출과 학습은 모두 0회다.

## 실패한 첫 수정도 보존

처음에는 부정 표현 처리 후 생성된 구분자까지 나눠 쉼표 연결이 깨졌다.
폐색전증 위험 신호 테스트 1개 실패, 합성 결과 384/400으로 하락했다.
이 버전은 채택하지 않았다. `original/`, `external_nine/`은 이 거부된 실험이다.
최종 결과는 `final_original/`, `final_external_nine/`이다.

## 남은 문제 / 다음 우선순위

이 수정만으로 미지원 질환을 진단할 수는 없다. 외부 복합 사례에서 다른 병명을
최종 선택하는 문제는 남아 있다. 문장 경계를 보존해도 한 문장 안의 과거력·원인·합병증,
쉼표로 열거된 서로 다른 신체 부위를 구분하는 완전한 의료 NLP는 아니다.

P1: 원문 병력/검사 구조화와 근거 출처 추적, 미지원 원인과 불확실성 판단을 별도 검증한다.
P1: 공모전 고정 모델의 실제 호출 경로를 연결·평가해야 한다. mock 결과를 LLM 성능으로 보지 않는다.
P3: 승인된 근거·질환 매핑을 확보한 뒤 미지원 프로필을 추가한다. 이번 9개를 정답 튜닝하고
독립 평가로 다시 보고하지 않는다. 별도 전문가 검토 사례가 필요하다.

수집된 DiagnosisArena 사례는 연구·평가 전용 조건을 유지한다.
