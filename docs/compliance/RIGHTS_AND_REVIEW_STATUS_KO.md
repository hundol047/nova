**실제 의료 전문가의 검토는 아직 없습니다.** 현재 결과는 권리 선언과 최신 검토 자료의 준비이며 임상 승인 완료가 아닙니다.

## 권리 기록의 근거와 한계

소유자가 이 대화에서 “직접 작성·의뢰했고 팀이 권리를 보유함”이라고 확인했고,
“공모전 제출·심사·관련 연구 발표에 한정해 사용·복제·필요한 수정을 허용”을 선택했습니다.
이 진술을 `artifacts/rights_and_review/owner_declaration.json`에 그대로 기록했고,
[TEAM_COMPETITION_PERMISSION.md](TEAM_COMPETITION_PERMISSION.md)에 적용 범위를 적었습니다.
서명·실명·기여 계약을 임의로 만들어 넣지 않았습니다. 독립적인 법률 검토를 받은 것은 아닙니다.

전체 100개 기존 기록의 Git 이력과 출처 참조는 `artifacts/rights_and_review/asset_evidence.json`에 있습니다.
Git 기록은 원저작권이나 정확한 생성 모델을 독립적으로 입증하지 않습니다.
코드·자료가 변경되면 기존 해시에 묶인 선언은 유효하지 않으며, 새 파일도 권한을 자동 상속하지 않습니다.
`TEAM_ORIGINAL_VERIFIED`는 이 선언 확인을 뜻하며 임상적 정확성의 검증 상태와 분리됩니다.

## 의료 전문가에게 전달할 자료

[최신 검토 문서](../clinical_review/CURRENT_REVIEW_KO.md)와
`artifacts/rights_and_review/clinical_review_packet.json`을 함께 전달하면 됩니다.
현재 핵심 34개와 최근 추가 8개 진단 프로필, 추론에 사용되는 파일의 해시를 포함합니다.
Tier-2 1,246개 전체의 검토나 실환자 성능 검증을 완료했다는 의미는 아닙니다.

우선 검토 질문은 약물 의존과 사용장애, 갑상샘 비대와 확진, 소아 성장·사춘기 판단,
응급 신호와 부정·시간·가족 정보, 추적 간격·약물 계획, 미시행 검사와 환자 근거의 분리입니다.
이것들은 엔지니어가 현재 코드·검토용 문헌에서 확인한 검토 쟁점이며 의사의 판정이 아닙니다.

검토 결과는 `clinician_response_template.json`을 복사해 작성합니다. 검토자 자격 확인 근거,
서명 근거, 날짜, 검토 항목, 근거 문헌, 적용 예외, 수정 권고를 남깁니다.
검증 도구는 빈 양식·AI 검토자·중복 항목·변경된 런타임·누락된 근거를 거부합니다.
부분 검토는 부분으로 집계하고, 실제 신원·자격 확인과 필요한 수정 반영은 별도로 진행합니다.
이 자료를 의사에게 보내거나 의뢰하는 연락은 실행하지 않았습니다.

## 검사 명령

```bash
python scripts/refresh_runtime_inventory.py --check
python scripts/validate_runtime_provenance.py --require-cleared
python scripts/prepare_rights_and_review.py --clinician-response <작성한 응답.json>
```

현재 빈 임상 응답 양식에 마지막 명령을 실행하면 종료 코드 2가 나오는 것이 정상입니다.
권리 검사는 기존 nova_agent 목록의 명시한 범위만 검사하고 ZIP 전체를 승인하지 않습니다.
ZIP 111개 파일의 별도 목록은 `artifacts/rights_and_review/archive_rights.json`입니다.
공식 문서 https://nova.snubhai.org/docs/ 의 “코드 제출 · 실행 계약”에는 SDK 포함 구조가 있습니다.
공모전 제출 사용과 목적 밖 SDK 공개 재배포의 범위를 구분했습니다.
현재 실제 임상 검토 및 주최 측 SDK의 별도 재배포 범위 확인이 남아 있어 공식 제출 승인 상태는 유지하지 않습니다.

이번 변경은 관리 도구·문서·증거만 수정했습니다. 진단 규칙과 ZIP의 바이트는 기존 v35 검증본과 같습니다.
현재 성능 검증 기록을 새 임상 검증 결과로 바꾸거나 공식 점수를 다시 산출하지 않았습니다.
