# v40 — 시작 시점의 미확인 처리와 재진 설명 정정

v39 이후 추가 검토에서 두 가지 재현 가능한 결함을 수정했다. 새로운 공식 점수나 채점 대화는 제공되지 않았다. 사용자가 마지막으로 보고한 점수는 합계 64.52점이다.

## 변경

1. 시작 시점을 묻는 질문에 “네”라고 답해도 시점이 확인된 것으로 간주하지 않는다. 이 경우 구체적인 시작 시점을 한 번 확인하며 v39의 항목당 1회·전체 3회 한도와 응급/종료 예산을 공유한다. 모름·거절은 반복하지 않는다.
2. 주호소 요약의 Onset에는 단순 긍정·부정·모름을 쓰지 않는다. 추가 확인에서 실제 시점이 나오면 최신 내용을 요약하며, 원래 질문과 답변도 HPI에 보존한다.
3. 환자가 안내한 재진 시점과 다른 시점을 말하면 이미 설명한 문장이어도 한 번 정정한다. 이해 확인 질문 자체를 반복하지 않는다. 방문이 어렵다는 답에는 일정과 도움을 상의하는 응답을 제공한다.
4. “네”, “감사합니다” 같은 응답에는 이미 전달한 계획을 반복하지 않는다. 정보 수집 전체 턴 제한, 응급 우선 처리, 미시행 검사 결과 공란을 유지한다.

## 검증

203개 집중 회귀를 통과했다. 새로운 회귀 17개와 기존 매개변수 회귀에 추가된 시작 시점 사례 1개를 포함한다. 단위 함수뿐 아니라 실제 설명 루프가 잘못된 재진 답변에 정정 발화를 생성하는지 확인했다.

Python 3.11/3.12 전체 회귀, SDK 230개 사례, 기존 합성 환자 3건, ZIP 독립 실행 및 가짜 HTTP 서버 검증 결과는 `artifacts/clinical_quality_v40`과 현재 검증 기록을 따른다. 기존 회귀 결과와 비교할 때 프로토콜·평가 스크립트 해시를 확인한다. Round M은 같은 SDK 실행의 정확한 부분집합이다.

## 한계

스크립트형 환자·Doctor 회귀는 실제 모델이나 공식 채점이 아니다. 실제 Doctor/API 호출, 주최 측 샘플·공식 평가, 새로운 비공개 블라인드 평가는 수행하지 않았다. 개발 키에 접근하지 않았다. 정적 누출 검사만 수행하며 기존 블라인드 자료를 진단 규칙에 맞춰 튜닝하지 않는다. 기존 외부 임상 검토·출처 권리 미해결 상태는 그대로 보존한다.

병렬 테스트 중 한 py312 하위 프로세스가 제출 폴더 재생성(delete/copy)과 겹쳐 일시적으로 모듈을 찾지 못했다. 다른 테스트가 끝난 뒤 영향받은 전체 묶음을 단독 재실행하여 1,080개를 모두 통과했고, 초기 실패와 재실행 범위는 `validation/packaging-race.json`에 남긴다. 진료 코드는 이 오류 때문에 변경하지 않았다.

최종 결과: Python 3.11/3.12 각각 2,916개 통과, 실패 0, 선택적 Torch 테스트 1개 제외. SDK 230건 중 기존과 같은 주진단 230건. 평균 턴 21.5087 → 21.5087. 실제 채점 점수 상승은 검증하지 않았다.
