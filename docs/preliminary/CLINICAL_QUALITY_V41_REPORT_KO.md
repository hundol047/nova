# v41 — 짧은 답변의 의미 보존과 관찰 근거의 전달

첨부된 v40 ZIP의 SHA-256은 공개한 파일과 일치한다. 사용자 보고 실제 점수는 정보수집 10.47, 진단추론 6.94, 검사·추적 3.67, 안전 11.25, 의사소통 6.44, 효율 18.68로 합계 **57.45점**이다. 이전 64.52점보다 **7.07점 하락**했다. 기존 합성 검증은 이 하락을 예측하지 못했다. 채점 대화가 없어 원인을 특정할 수 없으며, v41은 재현 가능한 소프트웨어 결함을 수정한 후보이지 실제 점수 회복이 입증된 버전이 아니다.

## 수정

- 추가 문진에서 “손 떨림이 있나요?” → “네”처럼 명확한 단일 증상을 물은 응답을 `associated_symptoms`라는 일반 분류만으로 저장하여, 증상 자체가 추론기에 전달되지 않는 경로를 고쳤다.
- 검증한 단일 증상 질문의 정확한 문구만 의미를 연결한다. 모델이 임의로 제시한 키를 신뢰하지 않는다. 복합 질문, 가족·과거 이야기, 부정형 질문, 양을 묻는 질문은 단순 긍정을 현재 환자 증상으로 바꾸지 않는다.
- “그렇습니다”, “네, 그렇습니다”, “네 맞아요”, “아닙니다”를 좁은 완전 일치형 긍정·부정으로 인식한다. “알겠습니다”는 증상 긍정으로 해석하지 않는다.
- 다른 표현으로 같은 증상을 묻더라도 이미 관찰했거나 시도한 질문은 반복하지 않는다. 선행 응답 이후 실행 시점에 다시 확인한다.
- Doctor가 사실 한 가지만 인용해도 실제 진찰과 주요 문진을 평가 근거에서 누락하지 않는다. 질문·답변·턴 출처를 보존하고 미확인을 부정 소견으로 쓰지 않는다.
- 특정 만성질환 프로필 외에도 실제 미해결 문진과 비교할 관찰을 추적 계획에 연결한다. Doctor의 추적 문구가 있어도 실제 미해결 복약 확인 과제가 사라지지 않도록 한다.
- 안전과 시간 여유가 있을 때 실제 지지 소견 두 가지를 짧은 환자용 문장으로 설명한다. 추가 진단이나 검사 결과를 만들지 않는다. 설명 1회가 추가될 수 있으며 무조건 효율 점수가 유지된다고 주장하지 않는다.

## 검증

전용 회귀 69개를 통과했다. 기존 v40과 같은 스크립트로 비교한 질문·답변 전달 검사에서 정확한 증상/부정/미확인 상태 연결이 0/18 → 18/18로 개선됐다. 복합·가족·과거·부정형·개방형 질문에 임의의 증상을 만들지 않는 보호 검사는 두 버전 모두 6/6이었다. 이는 결함을 겨냥한 소프트웨어 통합 회귀이며 임상 정답률이나 공식 정보수집 점수가 아니다. 추가 모델 호출은 없다.

Python 3.11/3.12 전체 회귀, 기존 SDK 230건, 합성 진료 3건 및 ZIP 실행 검증은 `artifacts/clinical_quality_v41`에 저장한다. 프로토콜과 평가 스크립트 해시가 같은 이전 결과와 비교한다. Round M은 SDK 결과의 정확한 부분집합이다.

지난 검증에서 확인한 제출 폴더 재생성 충돌을 방지하기 위해 패키징 테스트는 다른 테스트 뒤에 실행하며, 두 Python 버전은 동일 파일 트리의 별도 체크아웃에서 실행한다.

## 제한

실제 Doctor/API나 주최 측 평가, 신규 비공개 블라인드 평가는 수행하지 않았다. 개발 키도 접근하지 않았다. 기존 임상 검토·출처 권리 미해결 상태를 유지한다. 실제 영역별 점수 향상을 판단하려면 재평가 수치와 대화 기록이 필요하다.

최종 결과: Python 3.11/3.12 각각 2,985개 통과, 실패 0, 선택적 Torch 테스트 1개 제외. SDK 230건 중 기존과 같은 주진단 230건. 평균 턴 21.5087 → 21.5522. 실제 채점 점수 상승은 검증하지 않았다.
