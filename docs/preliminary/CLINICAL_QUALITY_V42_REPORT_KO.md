# v42 — 마무리 설명의 시간 조건 수정 후보

사용자 최신 점수는 62.23점(정보수집 11.10, 진단추론 8.19, 검사·추적 3.33, 안전 13.75, 의사소통 6.44, 효율 19.42)이다. 직전 57.45점보다 4.78점 상승했지만 검사·추적은 0.34점 하락, 의사소통은 동일하다. 대화 순서상 v41 평가로 추정하며 제출 파일 해시는 새로 확인하지 못했다.

## 재현한 결함과 변경

문진 종료 기준인 GATHER_MARGIN(240초)을 마무리 설명에도 사용하여, 남은 시간 30·60·120·239초에서 검사 목적·이해 확인·질문 수렴을 건너뛰었다. 같은 8개 회귀 테스트에서 v41은 5개 실패했고 수정 후 모두 통과했다. 이는 실제 채점 하락의 원인이라고 확정할 수 없으며, 재현한 실행 결함이다.

- 마무리 설명은 별도의 제출 여유 시간과 남은 턴으로 판단한다. 매 발화 전 다시 확인한다.
- 준비된 재진 안내를 실제 발화 목록에 넣고 동일 문구는 중복 전송하지 않는다.
- 검사 목적·재진·이해 확인·환자 질문을 선택적 근거 보충 설명보다 먼저 전달한다.
- 오해 교정과 질문 답변을 포함해 마무리 전체를 기존 10턴 예산 안에 제한한다. 응급 상황에는 일반 재진 대화를 추가하지 않는다.
- 진단 후보·치료 지침·문진 로직은 이 후보에서 변경하지 않았다. 시간이 적게 남은 비응급 사례에서는 설명 턴이 늘 수 있어 실제 효율 상승은 보장하지 않는다.

## 검증 범위

Python 3.12 관련 회귀 189개, 공식 어댑터·패키지 통합 88개 통과. Python 3.11 관련 회귀 94개 통과. 이전 통합 테스트의 ‘3분이면 3턴 이하’ 기대는 새 동작과 맞지 않아, 문진·진찰을 수행하지 않고 10턴 이내 설명과 이해 확인 후 완료하는지로 변경했다. 초기 결과도 보존했다.

최종 ZIP은 원본·제출 폴더와 Python 소스가 바이트 단위로 같고 독립 ZIP 실행 검증을 통과했다. 전체 회귀 및 SDK230은 이번에 다시 실행하지 않았다. `CURRENT_RELEASE.json`은 과거 v41의 전체 검증 기록이며, v42 후보의 정확한 파일 해시와 검사 범위는 `artifacts/releases/nova-v42-publication.json`을 따른다.

실제 Doctor 호출과 공식 재평가는 수행하지 않았다. 실제 대화 로그 없이 정보수집·진단추론 점수의 잔여 원인을 단정하지 않는다. 임상 검토와 출처 권리의 미확인 상태도 기존과 동일하다.
