# v43 — 감별 질문 예산과 세부 답변 연결

최근 사용자 보고는 63.34점: 정보수집 11.78, 진단추론 7.64, 검사·추적 4.67, 안전 15.00, 의사소통 6.44, 효율 17.81. 이전 62.23점 대비 총점은 1.11점 상승했으나 진단추론·효율은 하락했다. v42 평가로 추정하되 새 제출 파일 해시는 확인하지 못했다. 실제 대화 로그는 아직 없다.

## 수정

- 남은 수집 예산이 4턴 이하이면 일반 가족력·생활 영향·과거 진료·수술·흡연·음주 문진을 추가 감별 질문 뒤로 미룬다. 시작 시점·경과·과거 질환·복약·알레르기는 먼저 확인한다. 감별 단계 후 예산이 남으면 보류한 문진을 이어간다. 기존 전체 턴 한도를 늘리지 않는다.
- '병이 있나요? → 네' 다음의 검증된 병명 확인 질문을 이미 시도한 주제라는 이유로 차단하지 않는다. 기존의 필요한 세부 질문 선택기와 3개 상한을 그대로 적용한다. 부정·모름에는 같은 질문을 강요하지 않고, 답변 후 재질문하지 않는다.
- 일반적인 검사 목적과 치료 결정 안내가 둘 다 있을 때 한 문장으로 합친다. 구체적 약물 지시·경고 증상·재진 시점·이해 확인·질문 수렴은 삭제하지 않는다.
- 기본 문진을 두 번 나누어 수행해도 걱정 질문은 한 번만 한다. v42의 마감 보호와 마무리 10턴 한도를 유지한다.

## 관찰 결과

같은 두 결함 테스트는 이전 코드에서 실패하고 수정판에서 통과했다. 같은 180초 모의 상황은 8턴에서 7턴으로 줄었고 주진단은 동일했다. 기존 합성 진료 3건은 주진단과 항목 수집률이 같고 평균 29턴, 평균 Doctor 요청 2.333회로 변화가 없다. 따라서 전체 효율이나 임상 정확도가 개선됐다고 주장하지 않는다.

Python 3.12 관련 회귀 175개, SDK·패키지 통합 114개, 실행 도구 46개 통과(총 335개). Python 3.11 관련 회귀 106개 통과. 소스·제출 폴더·ZIP의 Python 파일은 바이트 단위 일치한다. ZIP 독립 모의 실행과 가짜 HTTP 서버를 통한 SDK 실행도 통과했다.

전체 회귀·SDK230·새 블라인드·실제 Doctor·공식 채점은 이번에 수행하지 않았다. `CURRENT_RELEASE.json`은 과거 v41 전체 검증 기록이며 이번 후보 해시와 범위는 `artifacts/releases/nova-v43-publication.json`에 있다. 실제 안전 만점 유지나 점수 상승은 검증되지 않았다. 기존 임상 검토·출처 권리 미확인 상태도 유지한다.

로컬 대화 수집 도구는 `--candidate v43`을 지원한다. v43 저장소와 ZIP을 사용하고, 개발 키 입력은 참가자 본인의 독립 PowerShell에서만 수행한다.
