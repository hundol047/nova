# v44 — 한국어 증상 질문과 환자 질문 응답

사용자는 총점이 64점으로 올랐다고 보고했다. 정확한 소수점·영역별 점수·새 제출 파일 해시는 제공되지 않았다. v43 평가로 추정하지만 확정하지 않는다. 실제 채점 대화는 아직 없다.

## 변경

기존의 16개 단일 증상 한국어 문구를 공유 모듈로 옮겨 기본 문진과 추가 문진이 함께 사용한다. 이전에는 기본 질문이 영어 특징명과 한국어 조사로 만들어져 별도 모델 번역을 거칠 수 있었다. 해당 16개 질문은 이제 추가 번역 호출 없이 30자 이내의 검증된 문구를 사용한다. 새 증상·질환·치료 규칙을 추가한 것은 아니다. 기존 긍정·부정·미확인 연결 검증도 유지한다.

환자의 응급 재진 기준 질문은 선택된 계획의 경고 증상 안내로 답한다. 진단 근거 질문은 실제로 검증된 관찰 근거를 재사용하며, 사용할 근거가 없으면 추가 확인 필요성을 알린다. 회복·완치 질문에는 원인을 확인하며 경과를 설명하겠다고 답하고 완치를 약속하지 않는다. 일반적인 걱정·불안 표현도 응답한다. 별도 모델 호출은 추가하지 않고 기존 마무리 10턴·마감 제한을 유지한다.

## 검증

같은 신규 회귀 75개를 이전 v43에서 실행하면 25개 실패·50개 통과였고, v44에서는 모두 통과했다. 이 중 16개는 한국어 질문과 번역 호출 생략, 48개는 증상별 긍정·부정·미확인 의미 보존, 나머지는 환자 질문 응답을 검증한다. 임상 정답률이나 공식 점수 검사는 아니다.

Python 3.12 관련 회귀 250개, 통합·패키징·출처 목록 검사 164개, 실행 도구 검사 51개: 총 465개 통과. Python 3.11 관련 회귀 95개 통과. 초기 패키징 검사 2개는 새 파일이 아직 Git 추적 대상이 아니어서 실패했다. 파일을 staging한 후 동일 패키징 모듈 전체와 출처 목록 검사를 다시 실행해 통과했고 최초 실패도 남겼다. 패키징 제한을 완화하지 않았다.

기존 합성 진료 3건은 주진단·문진 항목 수집률·평균 턴(29)·평균 Doctor 요청(2.333)이 이전과 같다. 이 사례들로 실제 점수 향상이나 전체 호출 비용 감소를 주장하지 않는다. 소스·제출 폴더·최종 ZIP의 Python 파일은 바이트 단위로 같고 ZIP 독립 실행 및 가짜 HTTP SDK 검증도 통과했다.

## 범위와 한계

전체 회귀·SDK230·신규 블라인드·실제 Doctor·공식 재평가는 수행하지 않았다. 과거 v41의 전체 검증을 가리키는 CURRENT_RELEASE.json은 유지하고 이번 후보의 해시·검증 범위는 artifacts/releases/nova-v44-publication.json에 명시한다. 임상 검토·출처 권리 미확인 상태는 유지한다. 점수 상승이나 완벽함을 보장하지 않는다. 실행 도구는 --candidate v44를 지원한다.
