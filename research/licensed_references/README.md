# Licensed source references, acquired 2026-10-05

This is a new reference dataset, not a reconstructed origin for existing NOVA heuristics.
`source_snapshot.json` retains the selected original publisher fields/HTML before text
normalization. `terms/` retains the publisher's actual reuse terms and Orphanet's CC BY license declaration
with URL/access date/SHA256. Original ZIP URLs, ZIP/member hashes and versions are in
both the snapshot and `scripts/import_licensed_references.py`.

Reproduce bundled text without network:

    python scripts/import_licensed_references.py build

Reacquire publisher inputs during development (not submitted inference):

    python scripts/import_licensed_references.py acquire

The ZIP hashes are pinned. If a publisher changes its file, acquisition stops for review.
The retained selected-field snapshot is sufficient to reproduce the bundled catalog even
if an original download disappears. ZIP/whole-page download caches are not committed.
Source markup is selected verbatim from permitted sections; metadata and JSON formatting
are generated by code. HTML tags are removed and whitespace is normalized. There is no
LLM-generated clinical text, translation, synthetic label or inferred diagnostic rule.

Selection uses the complete existing core/Tier-2 vocabulary, never benchmark answers,
blind labels, failures or patient data. Exact lexical links are not expert adjudication
of equivalent clinical concepts. Ambiguous same-publisher aliases are rejected at lookup.
English-only content is retained; no Korean/Japanese capability claim is made.

MedlinePlus: Source: MedlinePlus, National Library of Medicine. Health-topic summaries
and medical-test article sections only. Excludes A.D.A.M., ASHP drug monographs, images,
linked third-party content, reference bibliographies and site navigation. NLM's stated
public-domain scope and XML repurposing terms apply, not a blanket government-site license.

Orphanet (c) 2026, Nomenclature Pack July 2026, CC BY 4.0:
https://creativecommons.org/licenses/by/4.0/
Only active English disorder-level names, aliases and definitions are selected. Selection,
HTML removal and whitespace normalization are modifications. No source endorsement is
claimed; the license imposes attribution and modification notice requirements and does
not certify clinical correctness. Neither source clears legacy heuristic ownership/rights.
