## 재현해서 수정한 오류

1. 같은 검사에 정상값과 위험값이 함께 있으면 먼저 나오는 숫자를 채택했습니다. 입력 순서를 바꾸면 동일한 자료의 해석이 달라졌습니다. 이제 단일 검사 문자열 또는 개별 검사/패널 사이에서 서로 다른 숫자가 충돌하면 unknown으로 처리하고, 질적 표현으로 우회 확정하지 않습니다.
2. 과거 수치가 현재 수치보다 먼저 나오면 과거 수치를 채택했습니다. 이제 과거·기준값·참고범위로 명시된 절을 현재 측정값에서 제외합니다. 부정된 수치도 긍정 근거로 사용하지 않습니다.

동일 수치를 반복 기록한 경우는 충돌로 간주하지 않습니다. 애매한 시간 순서를 자동 추정하거나 수치 변환을 하지 않습니다. 글루코스·젖산 별도 파서는 이번 변경 대상이 아닙니다. 신규 회귀 사례 10개는 기존 동결 평가 문구를 사용하지 않은 파서 의미 검사입니다.

## 한계와 다음 검증 단계

- 원문에 질환명이 있다고 진단 기준이나 정확도가 검증되는 것은 아닙니다.
- 각 후보에는 전문가의 임상 의미·기존 개념과의 동등성 검토, 출처 기반 진단 근거, 독립 라벨 사례, 실제 모델 평가가 필요합니다. 이 작업으로 그러한 검토를 수행했다고 표시하지 않았습니다.
- 새로운 검토 후보는 자동 진단에 활성화하지 않았고, 기존 확장 게이트는 차단 상태입니다.
- 역사적 모의 평가는 반복 평가 자료이며 새로운 독립 임상 검증이 아닙니다. 실패 사례 문구나 정답에 맞춰 규칙을 추가하지 않았습니다.
